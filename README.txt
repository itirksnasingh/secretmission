R / PRACTICAL ARCHIVE — STUDY WEBSITE

WHAT'S INCLUDED
- index.html: complete static website.
- Experiments 1–8 from the supplied R Programming Practical Code Book, with searchable code sections and copy buttons.
- R package and CSV path setup notes.
- Exam Playbook: how to inspect an unfamiliar dataset, adapt column names, approach regression, troubleshoot common errors, and self-test core concepts.
- Dark interface, search, text-size/brightness/contrast controls, quick hide (Escape), and print/save-to-PDF.

IMPORTANT SOURCE LIMITATION
The source code book available for this build contains Experiments 1–8 only. Experiments 9 and 10 have not been invented or added. Send those source pages if they exist and the site can be updated.

EXAM / DATASET NOTES
- The website displays code; it does not run R code in the browser.
- CSV programs depend on the examiner's actual file name and column names.
- Use read.csv(file.choose()) to select a CSV file, then inspect it with head(), str(), names(), dim(), summary(), and colSums(is.na(data)).
- Replace example column names only after checking the supplied dataset.
- Install packages only when missing; installation may require internet. library() loads an installed package for the current R session.
- Use only tools and resources permitted by your examiner.

LOCAL PREVIEW
Open index.html in Chrome, Edge, Firefox, or Safari. No build step or external internet assets are required for the website UI.

PUBLISH WITH NETLIFY DROP
1. Open https://app.netlify.com/drop
2. Sign in if prompted.
3. Upload the folder containing index.html, or upload the ZIP if accepted.
4. Open the URL Netlify provides and keep the site in your account to manage it later.
